Γραμμική εκτίμηση κατάστασης (μοντέλο ΣΡ)¶

Τα παραδείγματα εφαρμόζουν τη μεθοδολογία της Ενότητας «Εκτίμηση κατάστασης» σε σύστημα τριών ζυγών. Το πρώτο παράδειγμα χρησιμοποιεί το γραμμικό μοντέλο ΣΡ και εξετάζει την εκτίμηση με σταθμισμένα ελάχιστα τετράγωνα, τον έλεγχο χ2\chi^2χ2, την αναγνώριση εσφαλμένης μέτρησης με το κριτήριο του μεγίστου κανονικοποιημένου υπολοίπου (LNR), την εύρωστη εκτίμηση WLAV και τη χρήση ψευδομετρήσεων. Το δεύτερο εφαρμόζει τη γενική μη γραμμική διατύπωση με πλήρες μοντέλο εναλλασσόμενου ρεύματος: συναρτήσεις μετρήσεων και αναλυτικό ιακωβιανό, επαναληπτική επίλυση Gauss–Newton, ακρίβεια της εκτίμησης, ανίχνευση χονδροειδούς σφάλματος και σύγκριση με το μοντέλο ΣΡ.

Επίλυση με σταθμισμένα ελάχιστα τετράγωνα¶

def wls(z, H, Rinv):
    """Εκτίμηση WLS με τα σχετικά μεγέθη ελέγχου."""
    G = H.T @ Rinv @ H                     # πίνακας κέρδους
    x_hat = np.linalg.solve(G, H.T @ Rinv @ z)
    r = z - H @ x_hat                      # υπόλοιπα
    J = float(r @ Rinv @ r)                # αντικειμενική συνάρτηση
    Omega = np.linalg.inv(Rinv) - H @ np.linalg.inv(G) @ H.T
    with np.errstate(divide="ignore", invalid="ignore"):
        rN = np.abs(r) / np.sqrt(np.diag(Omega))
    return x_hat, r, J, rN, Omega

Εύρωστη εκτίμηση WLAV¶

Ο εκτιμητής WLAV της Ενότητας «Παραλλαγές της εκτίμησης WLS» ελαχιστοποιεί το άθροισμα ∑i∣ri∣/σi\sum_i |r_i|/\sigma_i∑i​∣ri​∣/σi​ αντί για το άθροισμα των τετραγώνων των υπολοίπων. Στη γενική περίπτωση το πρόβλημα επιλύεται με γραμμικό προγραμματισμό και η λύση του έχει μηδενικό υπόλοιπο σε τουλάχιστον nnn μετρήσεις. Στο παράδειγμα, με n=2n = 2n=2, η λύση βρίσκεται επομένως απλούστερα: για κάθε ζεύγος μετρήσεων που προσδιορίζει και τις δύο γωνίες υπολογίζεται η κατάσταση που ικανοποιεί ακριβώς τις δύο μετρήσεις, και επιλέγεται εκείνη με το μικρότερο σταθμισμένο άθροισμα απόλυτων υπολοίπων. Η συνάρτηση wlav υλοποιεί αυτή την απαρίθμηση, η οποία είναι πρακτική μόνο για μικρά δίκτυα.

Οι δύο εκτιμητές συγκρίνονται σε τέσσερις περιπτώσεις χονδροειδών σφαλμάτων. Η εκτίμηση WLS υπολογίζεται χωρίς απόρριψη και με διαδοχική απόρριψη της μέτρησης με το μέγιστο κανονικοποιημένο υπόλοιπο, έως ότου ο έλεγχος χ2\chi^2χ2 δεν ανιχνεύει πλέον εσφαλμένα δεδομένα (εξωτερικός βρόχος, βλ. Σχήμα 11).

from itertools import combinations


def wlav(z, H, sig):
    """Εκτίμηση WLAV με απαρίθμηση: η λύση ικανοποιεί ακριβώς n μετρήσεις."""
    m_, n_ = H.shape
    best = None
    for S in combinations(range(m_), n_):
        HS = H[list(S)]
        if np.linalg.matrix_rank(HS) < n_:
            continue            # το ζεύγος δεν προσδιορίζει την κατάσταση
        x_S = np.linalg.solve(HS, z[list(S)])
        cost = float(np.sum(np.abs(z - H @ x_S) / sig))
        if best is None or cost < best[0]:
            best = (cost, x_S, S)
    _, x_hat, S = best
    return x_hat, z - H @ x_hat, S


CHI2_95 = {1: 3.841, 2: 5.991, 3: 7.815}      # κατώφλια χ² για πιθανότητα 95%


def wls_lnr(z, H, sig):
    """WLS με διαδοχική απόρριψη της μέτρησης με το μέγιστο r^N."""
    keep = list(range(len(z)))
    while True:
        Rinv_ = np.diag(1.0 / sig[keep]**2)
        x_, r_, J_, rN_, _ = wls(z[keep], H[keep], Rinv_)
        dof_ = len(keep) - H.shape[1]
        if dof_ == 0 or J_ <= CHI2_95[dof_]:
            return x_, [k for k in range(len(z)) if k not in keep]
        keep.pop(int(np.argmax(rN_)))

Ψευδομετρήσεις¶

Έστω ότι, λόγω βλαβών στην τηλεμετρία, διατίθεται μόνο η μέτρηση P12. Η γωνία θ3\theta_3θ3​ δεν προσδιορίζεται και το σύστημα δεν είναι παρατηρήσιμο (Ενότητα «Παρατηρησιμότητα»). Η παρατηρησιμότητα αποκαθίσταται με ψευδομετρήσεις των εγχύσεων P2 και P3, δηλαδή με προβλέψεις των φορτίων των ζυγών 2 και 3, με σφάλμα πρόβλεψης +15% και −10% αντίστοιχα. Στις ψευδομετρήσεις αποδίδεται τυπική απόκλιση 0,04 p.u., της τάξης του σφάλματος πρόβλεψης και τετραπλάσια από εκείνη των μετρητών. Για σύγκριση, η εκτίμηση επαναλαμβάνεται με τις ψευδομετρήσεις να θεωρούνται εξίσου ακριβείς με τους μετρητές. Η ακρίβεια κάθε εκτίμησης υπολογίζεται από τα διαγώνια στοιχεία του G−1\mathbf{G}^{-1}G−1.

Προτεινόμενες ασκήσεις (μοντέλο ΣΡ)¶

Προτείνονται οι ακόλουθες μεταβολές, με επανεκτέλεση των αντίστοιχων κελιών:

  • sigma: αύξηση σε 0.03. Πόσο μεγαλώνει το σφάλμα της εκτίμησης και ποιο μέγεθος χονδροειδούς σφάλματος παραμένει πλέον ανιχνεύσιμο;

  • bad_size: μείωση σε 2 * sigma. Ο έλεγχος χ2\chi^2χ2 εξακολουθεί να ανιχνεύει το σφάλμα;

  • bad_index: αλλοίωση της P2 αντί της P13. Το κριτήριο LNR αναγνωρίζει πάντοτε την αλλοιωμένη μέτρηση;

  • cases: προσθήκη περιπτώσεων με τρία ταυτόχρονα χονδροειδή σφάλματα. Δίνει και τότε η WLAV σωστή εκτίμηση;

  • forecast_error και sigma_ps: μεταβολή του σφάλματος πρόβλεψης και της τυπικής απόκλισης των ψευδομετρήσεων. Πώς μεταβάλλονται το σφάλμα και η τυπική απόκλιση της θ^3\hat{\theta}_3θ^3​; Τι αλλάζει αν στις διαθέσιμες μετρήσεις προστεθεί η P13;

Μη γραμμική εκτίμηση κατάστασης (μοντέλο ΕΡ)¶

Το παράδειγμα εφαρμόζει τη γενική μη γραμμική διατύπωση της Ενότητας «Εκτίμηση κατάστασης» στο ίδιο δίκτυο τριών ζυγών, με πλήρες μοντέλο κλάδων (ωμική αντίσταση, αντίδραση σειράς και εγκάρσια χωρητική επιδεκτικότητα) και μετρήσεις μέτρων τάσης, ροών και εγχύσεων ενεργής και άεργης ισχύος. Οι συναρτήσεις μετρήσεων και ο ιακωβιανός πίνακας υλοποιούνται αναλυτικά σύμφωνα με τις σχέσεις της ίδιας ενότητας και η εκτίμηση υπολογίζεται με τη μέθοδο Gauss–Newton από επίπεδο προφίλ.

Συναρτήσεις μετρήσεων και ιακωβιανός πίνακας¶

Κάθε μέτρηση περιγράφεται από το είδος της (V, Pi, Qi, Pf, Qf) και τους ζυγούς στους οποίους αναφέρεται. Η συνάρτηση h_ac υλοποιεί τις σχέσεις εγχύσεων και ροών της Ενότητας «Συναρτήσεις μετρήσεων» και η H_ac τις αναλυτικές παραγώγους τους. Το διάνυσμα κατάστασης είναι x=[θ2,θ3,V1,V2,V3]T\mathbf{x} = [\theta_2, \theta_3, V_1, V_2, V_3]^{T}x=[θ2​,θ3​,V1​,V2​,V3​]T με θ1=0\theta_1 = 0θ1​=0.

def unpack(x):
    """Γωνίες (με θ1 = 0) και μέτρα τάσεων από το διάνυσμα κατάστασης."""
    return np.r_[0.0, x[:NB - 1]], x[NB - 1:]


def h_ac(x, meas, Y, pi):
    th, V = unpack(x)
    G, B = Y.real, Y.imag
    h = np.zeros(len(meas))
    for k, (kind, i, j) in enumerate(meas):
        if kind == "V":
            h[k] = V[i]
        elif kind in ("Pi", "Qi"):
            c, s = np.cos(th[i] - th), np.sin(th[i] - th)
            if kind == "Pi":
                h[k] = V[i] * np.sum(V * (G[i] * c + B[i] * s))
            else:
                h[k] = V[i] * np.sum(V * (G[i] * s - B[i] * c))
        else:
            g, b, bs = pi[(i, j)]
            c, s = np.cos(th[i] - th[j]), np.sin(th[i] - th[j])
            if kind == "Pf":
                h[k] = V[i]**2 * g - V[i] * V[j] * (g * c + b * s)
            else:
                h[k] = -V[i]**2 * (b + bs) - V[i] * V[j] * (g * s - b * c)
    return h


def H_ac(x, meas, Y, pi):
    th, V = unpack(x)
    G, B = Y.real, Y.imag
    Hf = np.zeros((len(meas), 2 * NB))        # στήλες: θ1..θN, V1..VN
    for k, (kind, i, j) in enumerate(meas):
        if kind == "V":
            Hf[k, NB + i] = 1.0
        elif kind in ("Pi", "Qi"):
            cv, sv = np.cos(th[i] - th), np.sin(th[i] - th)
            Pi = V[i] * np.sum(V * (G[i] * cv + B[i] * sv))
            Qi = V[i] * np.sum(V * (G[i] * sv - B[i] * cv))
            Gii, Bii = G[i, i], B[i, i]
            for q in range(NB):
                c, s = cv[q], sv[q]
                if q == i and kind == "Pi":
                    Hf[k, i] = -Qi - Bii * V[i]**2
                    Hf[k, NB + i] = Pi / V[i] + Gii * V[i]
                elif q == i:
                    Hf[k, i] = Pi - Gii * V[i]**2
                    Hf[k, NB + i] = Qi / V[i] - Bii * V[i]
                elif kind == "Pi":
                    Hf[k, q] = V[i] * V[q] * (G[i, q] * s - B[i, q] * c)
                    Hf[k, NB + q] = V[i] * (G[i, q] * c + B[i, q] * s)
                else:
                    Hf[k, q] = -V[i] * V[q] * (G[i, q] * c + B[i, q] * s)
                    Hf[k, NB + q] = V[i] * (G[i, q] * s - B[i, q] * c)
        else:
            g, b, bs = pi[(i, j)]
            c, s = np.cos(th[i] - th[j]), np.sin(th[i] - th[j])
            if kind == "Pf":
                dth = V[i] * V[j] * (g * s - b * c)
                Hf[k, i], Hf[k, j] = dth, -dth
                Hf[k, NB + i] = -V[j] * (g * c + b * s) + 2 * g * V[i]
                Hf[k, NB + j] = -V[i] * (g * c + b * s)
            else:
                dth = -V[i] * V[j] * (g * c + b * s)
                Hf[k, i], Hf[k, j] = dth, -dth
                Hf[k, NB + i] = (-V[j] * (g * s - b * c)
                                 - 2 * V[i] * (b + bs))
                Hf[k, NB + j] = -V[i] * (g * s - b * c)
    return np.delete(Hf, 0, axis=1)       # χωρίς τη στήλη της θ1

Επίλυση με τη μέθοδο Gauss–Newton¶

Η συνάρτηση wls_ac υλοποιεί τον αλγόριθμο της Ενότητας «Εκτίμηση σταθμισμένων ελαχίστων τετραγώνων»: σε κάθε επανάληψη υπολογίζει τα h(xk)\mathbf{h}(\mathbf{x}^{k})h(xk), H(xk)\mathbf{H}(\mathbf{x}^{k})H(xk) και G(xk)\mathbf{G}(\mathbf{x}^{k})G(xk), επιλύει τις κανονικές εξισώσεις και ελέγχει τη σύγκλιση με ανοχή 10-6.

def wls_ac(z, sig, meas, Y, pi, x0, tol=1e-6, itmax=20, verbose=False):
    """Εκτίμηση WLS με τη μέθοδο Gauss–Newton."""
    Rinv = np.diag(1 / sig**2)
    x, history = x0.astype(float).copy(), []
    for k in range(itmax):
        r = z - h_ac(x, meas, Y, pi)
        H = H_ac(x, meas, Y, pi)
        G = H.T @ Rinv @ H
        dx = np.linalg.solve(G, H.T @ Rinv @ r)
        history.append((k, float(r @ Rinv @ r), np.abs(dx).max()))
        if verbose:
            _, Jk, step = history[-1]
            print(f"k = {k}   J(x^k) = {Jk:10.3f}   max|Δx| = {step:.2e}")
        x = x + dx
        if np.abs(dx).max() < tol:
            break
    r = z - h_ac(x, meas, Y, pi)
    H = H_ac(x, meas, Y, pi)
    G = H.T @ Rinv @ H
    Omega = np.diag(sig**2) - H @ np.linalg.solve(G, H.T)
    with np.errstate(divide="ignore", invalid="ignore"):
        rN = np.abs(r) / np.sqrt(np.diag(Omega))
    return dict(x=x, r=r, J=float(r @ Rinv @ r), rN=rN, G=G,
                history=history)

        for a, b, _, x, _ in kladoi:
            a, b = a - 1, b - 1
            if kind == "Pf" and {a, b} == {i, j}:
                Hd[row, i] += 1 / x
                Hd[row, j] -= 1 / x
            elif kind == "Pi" and i in (a, b):
                other = b if a == i else a
                Hd[row, i] += 1 / x
                Hd[row, other] -= 1 / x
    Hd, W = Hd[:, 1:], np.diag(1 / sig[rows]**2)
    return np.linalg.solve(Hd.T @ W @ Hd, Hd.T @ W @ z[rows])
