## Εκτίμηση κατάστασης σε σύστημα τριών ζυγών

Το παράδειγμα που ακολουθεί υλοποιεί ολόκληρη την αλυσίδα της §1.1.6 σε ένα σύστημα
τριών ζυγών: σχηματισμό του μοντέλου μέτρησης, επίλυση με σταθμισμένα ελάχιστα τετράγωνα,
έλεγχο $\chi^2$, αναγνώριση εσφαλμένης μέτρησης με το κριτήριο του μεγίστου
κανονικοποιημένου υπολοίπου, και τέλος τα δύο θεμελιώδη όρια της μεθόδου — τις κρίσιμες
μετρήσεις και τις επιθέσεις έγχυσης ψευδών δεδομένων. Ακολουθεί τη διάταξη των κλασικών
παραδειγμάτων του Monticelli και των Abur και Gómez Expósito.

:::{tip} Διαδραστική εκτέλεση
Τα κελιά που ακολουθούν εκτελούνται μέσα στον φυλλομετρητή, χωρίς εγκατάσταση. Με το
κουμπί **έναρξης περιβάλλοντος υπολογισμού** ενεργοποιείται ο πυρήνας — η πρώτη φόρτωση
διαρκεί μερικά δευτερόλεπτα — και στη συνέχεια κάθε κελί εκτελείται με το δικό του κουμπί
εκτέλεσης.

Για πειραματισμό υπάρχουν δύο δρόμοι. Ο απλός είναι το κελί με τους **ολισθητές** στην
§1.2.1.8, που μεταβάλλει τις παραμέτρους χωρίς επέμβαση στον κώδικα. Ο πλήρης είναι το
κουμπί **ανοίγματος σε Jupyter**, το οποίο φορτώνει τη σελίδα ως σημειωματάριο όπου ο
κώδικας κάθε κελιού μπορεί να τροποποιηθεί ελεύθερα.
:::

### Το δίκτυο και το γραμμικό μοντέλο

Χρησιμοποιείται το μοντέλο συνεχούς ρεύματος (DC), στο οποίο οι απώλειες αμελούνται, τα
μέτρα των τάσεων θεωρούνται μοναδιαία και οι γωνίες μικρές. Η ροή σε κλάδο και η έγχυση
σε ζυγό γίνονται τότε **γραμμικές** ως προς τις γωνίες:

$$
P_{ij} = \frac{\theta_i - \theta_j}{x_{ij}}, \qquad
P_i = \sum_{j \in \Omega_i} \frac{\theta_i - \theta_j}{x_{ij}}
$$

Ο ζυγός 1 λαμβάνεται ως αναφορά με $\theta_1 = 0$, οπότε η κατάσταση είναι
$\mathbf{x} = [\theta_2, \theta_3]^{T}$ και $n = 2$. Επειδή το μοντέλο είναι γραμμικό, ο
ιακωβιανός $\mathbf{H}$ είναι σταθερός και η λύση προκύπτει σε ένα βήμα, χωρίς επαναλήψεις.

```{code-cell} python
import numpy as np

np.set_printoptions(precision=4, suppress=True)

# --- παράμετροι δικτύου (αντιδράσεις κλάδων, ανά μονάδα) ---
x12, x13, x23 = 0.20, 0.40, 0.25

# Μετρήσεις: τρεις ροές κλάδων και δύο εγχύσεις ζυγών.
names = ["P12", "P13", "P23", "P2", "P3"]

H = np.array([
    [-1/x12,          0.0            ],   # P12 = (θ1 - θ2)/x12
    [ 0.0,           -1/x13          ],   # P13 = (θ1 - θ3)/x13
    [ 1/x23,         -1/x23          ],   # P23 = (θ2 - θ3)/x23
    [ 1/x12 + 1/x23, -1/x23          ],   # P2  = έγχυση στον ζυγό 2
    [-1/x23,          1/x13 + 1/x23  ],   # P3  = έγχυση στον ζυγό 3
])

n = H.shape[1]
m = H.shape[0]
print(f"m = {m} μετρήσεις, n = {n} άγνωστοι, λόγος πλεονασμού η = {m/n:.1f}")
print("H =", H, sep="\n")
```

### Παραγωγή των μετρήσεων

Για να είναι ελέγξιμο το αποτέλεσμα, οι μετρήσεις παράγονται από μια *γνωστή* κατάσταση
με προσθήκη θορύβου. Στην πραγματικότητα η κατάσταση είναι άγνωστη· εδώ διατηρείται ώστε
να συγκριθεί με την εκτίμηση.

```{code-cell} python
# --- παράμετροι: αληθής κατάσταση και ακρίβεια μετρητών ---
theta_true = np.array([-0.05, -0.08])   # γωνίες ζυγών 2 και 3 σε rad
sigma = 0.01                            # τυπική απόκλιση κάθε μετρητή, ανά μονάδα
seed = 2026                             # για αναπαραγώγιμο θόρυβο

R = np.diag(np.full(m, sigma**2))
Rinv = np.linalg.inv(R)

rng = np.random.default_rng(seed)
z_clean = H @ theta_true
z = z_clean + rng.normal(0.0, sigma, m)

for k, nm in enumerate(names):
    print(f"{nm:>4}:  αληθής {z_clean[k]:+.4f}   μετρούμενη {z[k]:+.4f}")
```

### Επίλυση με σταθμισμένα ελάχιστα τετράγωνα

```{code-cell} python
def wls(z, H, Rinv):
    """Εκτίμηση WLS με τα σχετικά μεγέθη ελέγχου."""
    G = H.T @ Rinv @ H                     # πίνακας κέρδους
    x_hat = np.linalg.solve(G, H.T @ Rinv @ z)
    r = z - H @ x_hat                      # υπόλοιπα
    J = float(r @ Rinv @ r)                # αντικειμενική συνάρτηση
    Omega = np.linalg.inv(Rinv) - H @ np.linalg.inv(G) @ H.T
    with np.errstate(divide="ignore", invalid="ignore"):
        rN = np.abs(r) / np.sqrt(np.diag(Omega))
    return x_hat, r, J, rN, Omega


x_hat, r, J, rN, Omega = wls(z, H, Rinv)

print("θ̂        =", x_hat)
print("θ αληθής  =", theta_true)
print("σφάλμα    =", (x_hat - theta_true) * 1e3, "mrad")
```

Η εκτίμηση πλησιάζει την αληθή κατάσταση σε λίγα χιλιοστά του rad, παρότι καμία μεμονωμένη
μέτρηση δεν είναι ακριβής. Αυτό ακριβώς προσφέρει ο πλεονασμός.

### Έλεγχος $\chi^2$

Οι βαθμοί ελευθερίας είναι $m - n = 3$ και το κατώφλι για επίπεδο εμπιστοσύνης 95\%
είναι $\chi^2_{3,\,0{,}95} = 7{,}815$.

```{code-cell} python
dof = m - n
chi2_crit = 7.815      # χ² για 3 βαθμούς ελευθερίας, 95%

print(f"J = {J:.3f}   βαθμοί ελευθερίας = {dof}   κατώφλι = {chi2_crit}")
print("Αποτέλεσμα:", "ένδειξη εσφαλμένων δεδομένων" if J > chi2_crit else "καθαρά δεδομένα")
print()
for k, nm in enumerate(names):
    print(f"{nm:>4}:  r = {r[k]:+.4f}   r^N = {rN[k]:.2f}")
```

### Χονδροειδές σφάλμα: ανίχνευση και αναγνώριση

Στη μέτρηση `P13` προστίθεται σφάλμα οκτώ τυπικών αποκλίσεων — μια τιμή που φαίνεται
απολύτως εύλογη αν εξεταστεί μεμονωμένα.

```{code-cell} python
# --- παράμετροι: ποια μέτρηση αλλοιώνεται και κατά πόσο ---
bad_index = names.index("P13")
bad_size = 8 * sigma

z_bad = z.copy()
z_bad[bad_index] += bad_size

x_b, r_b, J_b, rN_b, _ = wls(z_bad, H, Rinv)
suspect = int(np.argmax(rN_b))

print(f"J = {J_b:.1f}  έναντι κατωφλίου {chi2_crit}  ->  ανιχνεύεται")
print(f"μέγιστο r^N: {names[suspect]}  ({rN_b[suspect]:.2f})")
print()

keep = [i for i in range(m) if i != suspect]
x_c, r_c, J_c, _, _ = wls(z_bad[keep], H[keep], np.linalg.inv(R[np.ix_(keep, keep)]))
print(f"μετά την απόρριψη της {names[suspect]}:")
print(f"  θ̂ = {x_c}   J = {J_c:.3f}   βαθμοί ελευθερίας = {len(keep) - n}")
print(f"  σφάλμα ως προς την αληθή κατάσταση = {(x_c - theta_true) * 1e3} mrad")
```

```{code-cell} python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(6.2, 3.0))
xpos = np.arange(m)
ax.bar(xpos - 0.2, rN, width=0.4, label="καθαρά δεδομένα", color="#5b6b78")
ax.bar(xpos + 0.2, rN_b, width=0.4, label="με χονδροειδές σφάλμα", color="#8f2622")
ax.axhline(3.0, ls="--", lw=1.1, color="#1f2a33")
ax.text(-0.45, 3.2, "κατώφλι 3σ", ha="left", fontsize=9)
ax.set_ylim(0, max(rN_b.max(), 3.0) * 1.18)
ax.set_xticks(xpos, names)
ax.set_ylabel("κανονικοποιημένο υπόλοιπο")
ax.legend(fontsize=9, frameon=False)
fig.tight_layout()
```

Το σφάλμα δεν εντοπίζεται από τη μέτρηση καθεαυτή, αλλά από την **ασυμφωνία της με τις
υπόλοιπες**. Χωρίς πλεονασμό δεν θα υπήρχε τίποτα να τη διαψεύσει.

### Πρώτο όριο: κρίσιμες μετρήσεις

Αν το σύνολο περιοριστεί στις `P12` και `P13`, οι δύο μετρήσεις αρκούν ίσα-ίσα για τον
προσδιορισμό των δύο αγνώστων. Καθεμιά γίνεται τότε κρίσιμη.

```{code-cell} python
sub = [names.index("P12"), names.index("P13")]
Rs = np.linalg.inv(R[np.ix_(sub, sub)])
x_s, r_s, J_s, _, Om_s = wls(z[sub], H[sub], Rs)

print("διαγώνιος του Ω =", np.diag(Om_s))
print("υπόλοιπα        =", r_s)
print(f"J = {J_s:.1e}  με {len(sub) - n} βαθμούς ελευθερίας")
print()
z_s = z[sub].copy()
z_s[0] += 0.5                      # τεράστιο σφάλμα στην P12
x_s2, r_s2, J_s2, _, _ = wls(z_s, H[sub], Rs)
print("με σφάλμα +0.5 στην P12:")
print(f"  υπόλοιπα = {r_s2}   J = {J_s2:.1e}")
print(f"  θ̂ = {x_s2}  έναντι αληθούς {theta_true}")
```

Το υπόλοιπο παραμένει μηδενικό και το τεστ $\chi^2$ δεν έχει βαθμούς ελευθερίας: το
σφάλμα είναι **μη ανιχνεύσιμο**, ενώ η εκτίμηση έχει μετατοπιστεί δραστικά.

### Δεύτερο όριο: επίθεση έγχυσης ψευδών δεδομένων

Ο επιτιθέμενος γνωρίζει τον $\mathbf{H}$ και κατασκευάζει το διάνυσμα επίθεσης ως
$\mathbf{a} = \mathbf{H}\mathbf{c}$. Το πλήρες σύνολο των πέντε μετρήσεων παραμένει
διαθέσιμο.

```{code-cell} python
# --- παράμετρος: η επιθυμητή μετατόπιση της εκτιμώμενης κατάστασης ---
c = np.array([0.004, 0.004])       # rad

a = H @ c                          # συνεπές με το μοντέλο διάνυσμα επίθεσης
z_att = z + a
x_a, r_a, J_a, rN_a, _ = wls(z_att, H, Rinv)

print("αλλοίωση ανά μέτρηση =", a)
print()
print(f"J χωρίς επίθεση = {J:.4f}")
print(f"J με επίθεση    = {J_a:.4f}")
print(f"μέγιστη διαφορά υπολοίπων = {np.max(np.abs(r - r_a)):.2e}")
print(f"μέγιστο r^N = {rN_a.max():.2f}  (κατώφλι 3)")
print()
print("θ̂ χωρίς επίθεση =", x_hat)
print("θ̂ με επίθεση    =", x_a)
print("διαφορά          =", x_a - x_hat, " ενώ c =", c)
```

Τα υπόλοιπα είναι **αριθμητικά ταυτόσημα** και το $J$ αμετάβλητο, ενώ η εκτιμώμενη
κατάσταση έχει μετατοπιστεί ακριβώς κατά $\mathbf{c}$. Κανένας έλεγχος βασισμένος στα
υπόλοιπα δεν μπορεί να το εντοπίσει, όσο αυστηρό και αν είναι το κατώφλι. Το ζήτημα
εξετάζεται στο Κεφάλαιο 8.

### Πειραματιστήριο με ολισθητές

Το κελί που ακολουθεί επαναλαμβάνει ολόκληρη τη διαδικασία για όποιον συνδυασμό
παραμέτρων επιλεγεί. Κάθε μετακίνηση ολισθητή προκαλεί νέο υπολογισμό: παράγονται νέες
μετρήσεις, αλλοιώνεται η επιλεγμένη, εκτελείται η εκτίμηση και ελέγχεται αν το τεστ
$\chi^2$ ανιχνεύει το σφάλμα και αν το κριτήριο του μεγίστου κανονικοποιημένου υπολοίπου
αναγνωρίζει τη σωστή μέτρηση.

```{code-cell} python
# Το ipywidgets δεν περιλαμβάνεται στο περιβάλλον του φυλλομετρητή, οπότε
# εγκαθίσταται κατά την εκτέλεση. Αν αποτύχει, το κελί υποχωρεί σε στατική εκτέλεση.
try:
    import ipywidgets as widgets
    OLISTHITES = True
except ModuleNotFoundError:
    try:
        import micropip
        await micropip.install("ipywidgets")
        import ipywidgets as widgets
        OLISTHITES = True
    except Exception as exc:
        OLISTHITES = False
        print("Οι ολισθητές δεν είναι διαθέσιμοι:", exc)


def peirama(sigma_pu=0.01, metrisi="P13", megethos=8.0, seed=2026):
    R_ = np.diag(np.full(m, sigma_pu**2))
    Rinv_ = np.linalg.inv(R_)
    rng_ = np.random.default_rng(int(seed))

    z_ = H @ theta_true + rng_.normal(0.0, sigma_pu, m)
    k = names.index(metrisi)
    z_[k] += megethos * sigma_pu                      # το χονδροειδές σφάλμα

    x_, r_, J_, rN_, _ = wls(z_, H, Rinv_)
    entopismeni = names[int(np.argmax(rN_))]
    anichneuetai = J_ > chi2_crit

    fig, ax = plt.subplots(figsize=(6.2, 2.8))
    colors = ["#8f2622" if nm == metrisi else "#5b6b78" for nm in names]
    ax.bar(np.arange(m), rN_, color=colors, width=0.55)
    ax.axhline(3.0, ls="--", lw=1.1, color="#1f2a33")
    ax.set_xticks(np.arange(m), names)
    ax.set_ylabel("κανονικοποιημένο υπόλοιπο")
    ax.set_ylim(0, max(rN_.max(), 3.5) * 1.15)
    ax.set_title(
        f"J = {J_:.1f}   (κατώφλι {chi2_crit})   ->   "
        + ("ανιχνεύεται" if anichneuetai else "ΔΕΝ ανιχνεύεται"),
        fontsize=10,
    )
    plt.show()

    print(f"αλλοιωμένη: {metrisi}   ύποπτη κατά το κριτήριο: {entopismeni}", end="   ")
    print("[σωστή]" if entopismeni == metrisi and anichneuetai else "[αστοχία]")
    print(f"σφάλμα εκτίμησης = {(x_ - theta_true) * 1e3} mrad")


if OLISTHITES:
    _ = widgets.interact(          # η ανάθεση αποτρέπει την εκτύπωση του repr
        peirama,
        sigma_pu=widgets.FloatSlider(value=0.01, min=0.002, max=0.05, step=0.002,
                                     description="σ (pu)", readout_format=".3f"),
        metrisi=widgets.Dropdown(options=names, value="P13", description="μέτρηση"),
        megethos=widgets.FloatSlider(value=8.0, min=0.0, max=20.0, step=0.5,
                                     description="σφάλμα (×σ)"),
        seed=widgets.IntSlider(value=2026, min=1, max=50, description="δείγμα"),
    )
else:
    peirama()
```

Δύο συμπεράσματα προκύπτουν γρήγορα από τον πειραματισμό. Πρώτον, καθώς το μέγεθος του
σφάλματος μικραίνει προς τις δύο τυπικές αποκλίσεις, η ανίχνευση γίνεται αναξιόπιστη: το
σφάλμα χάνεται μέσα στον θόρυβο. Δεύτερον, όταν αλλοιώνεται μια **έγχυση** αντί για ροή
κλάδου, το κριτήριο του μεγίστου κανονικοποιημένου υπολοίπου αστοχεί συχνότερα, επειδή οι
εγχύσεις εμπλέκουν περισσότερους κλάδους και το σφάλμα διαχέεται σε περισσότερα υπόλοιπα.

### Προτεινόμενοι πειραματισμοί

Οι επόμενες μεταβολές αξίζουν δοκιμής, με επανεκτέλεση των κελιών:

- **`sigma`**: αύξηση σε `0.03`. Πόσο μεγαλώνει το σφάλμα της εκτίμησης και ποιο μέγεθος
  χονδροειδούς σφάλματος παραμένει πλέον ανιχνεύσιμο;
- **`bad_size`**: μείωση σε `2 * sigma`. Το τεστ $\chi^2$ εξακολουθεί να ανιχνεύει;
- **`bad_index`**: αλλοίωση της `P2` αντί της `P13`. Το κριτήριο του μεγίστου
  κανονικοποιημένου υπολοίπου αναγνωρίζει πάντοτε τη σωστή;
- **`c`**: μεταβολή του διανύσματος επίθεσης. Υπάρχει τιμή που να αυξάνει το $J$;
- Αφαίρεση της `P23` από το σύνολο, ώστε ο πλεονασμός να πέσει σε $\eta = 2$. Ποιες
  μετρήσεις γίνονται κρίσιμες;
